# Changelog

All notable changes to **Byte Utility 🦝** are documented here.
This project follows [Semantic Versioning](https://semver.org/).

## [1.1.1] — 2026-09-29

- Scheduled greetings (morning, noon, night) now post only in #🦝・byte-club instead of #welcome and #off-topic.
- Auto-role now looks for the renamed `🦝 Member` role.

## [1.1.0] — 2026-09-29

- New app logo in the AkihiroLabs family style (navy base, white symbol, violet accent): `app-icon.png`, `favicon.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`.
- README explains how to set it as the bot avatar.

## [1.0.0] — 2026-09-28

- Added `README.md`, `CHANGELOG.md` and `.env.example`.
- Current features: scheduled JST greetings, welcome messages + auto role, anti-spam timeouts, slash commands, mod log.
